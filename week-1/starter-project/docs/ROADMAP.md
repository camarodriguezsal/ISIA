# Roadmap de Producto y Operaciones — IncidentOps

| Hito | Iniciativa | Valor de Negocio y Alcance Operativo | Estado |
| :--- | :--- | :--- | :--- |
| **H001** | Triaje multi-interfaz | Exponer la clasificación y el enrutamiento determinista de reportes sin persistencia para consumo inmediato desde web y terminal. | Pendiente |
| **H002** | Resumen de incidentes activos | Permitir consultar los incidentes actualmente activos, sus incumplimientos de SLA y el filtrado por componente desde web y terminal. | Pendiente |
| **H003** | Ciclo de vida, duplicados y SLA | Registrar incidentes entrantes de forma persistente, alertar si ya existe un incidente equivalente abierto y auditar su estado de SLA en cualquier instante de referencia. | Pendiente |
| **H004** | Persistencia relacional dedicada y runtime en contenedores | Preparar el servicio para una ejecución reproducible en contenedores con base de datos relacional dedicada y verificación real de conectividad operativa. | Pendiente |
